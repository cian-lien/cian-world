# 任务：用 Blender MCP 制作「3D 房间博客」的房间模型

## 背景
我在做一个个人博客网站：页面上是一个俯视 3/4 视角的 3D 卡通小房间，访客点击房间里的物件来浏览内容（点日记本看文章，点电脑打开一个仿桌面系统）。前端用 React Three Fiber，代码仓库是 `room-blog`，需求文档在 `docs/SPEC.md`（第 8 节是 3D 场景规格）。
你的任务是通过 Blender MCP 在 Blender 里建出这个房间，最后导出 `public/models/room.glb` 和烘焙贴图，供前端加载。

## 工作规则（必须遵守）
1. 开始前先用 MCP 查看当前场景和 Blender 版本（如 get_scene_info），告诉我版本号和场景里已有的物体。场景里有不是你创建的物体时，先问我，不要删。
2. 用 Python（bpy，如 execute_blender_code）分小步建模，每次只做一组物体。每段脚本都要能重复运行：先按名字删除旧对象，再重新创建。
3. 每完成一个阶段，截一张视口图（如 get_viewport_screenshot），从 `Cam_Room` 视角看，自己检查比例、穿模、悬空、朝向，有问题先修好再继续。
4. 每个阶段结束后保存 `.blend` 到 `assets/blender/room.blend`（相对仓库根目录），并保留上一版备份 `room_prev.blend`。
5. 第 6 阶段（整体检查）完成后停下来，把截图发给我确认，得到我同意后再做 UV、烘焙和导出（烘焙很慢）。
6. 单位用米，Blender 默认 Z 轴向上。不要使用任何外部素材库（Poly Haven、Sketchfab、AI 生成模型等），全部用基础几何体手工建模。
7. 对象名是前端代码依赖的契约，必须和下文完全一致，区分大小写。

## 风格
- 温暖、可爱的低多边形微缩模型风格，参考 bruno-simon.com 的质感：圆润、纯色块、无写实纹理。
- 几乎所有方块都加 Bevel 修改器（宽度 0.01–0.04，段数 2–3），保证边缘圆润。
- 材质只用 Principled BSDF 纯色：Roughness 0.7–0.85，Metallic 0，不用图片贴图。
- 下文颜色是 sRGB 十六进制。设置 Base Color 前必须转换成线性值：
  `lin = c/12.92 if c <= 0.04045 else ((c+0.055)/1.055) ** 2.4`
- 面数预算：整个场景不超过 60,000 个三角面。圆柱和球体用 16–24 段即可。

## 坐标约定（Blender 坐标，Z 向上）
- 房间中心在原点，地板顶面 Z = 0。
- 只有两面墙：后墙内表面在 Y = +3.0，左墙内表面在 X = −3.0。右侧（+X）和前方（−Y）敞开，镜头从 (+X, −Y) 方向斜上方俯视。
- 前端换算：three.js (x, y, z) = Blender (X, Z, −Y)。导出时勾选 +Y Up，转换会自动完成。

## 灯光（只用于烘焙和预览）
- 太阳光：从窗户方向斜射入房间，暖白色 #fff1dc，强度约 3。
- 窗户位置放一盏面光源（Area），浅蓝色，补充窗光。
- 台灯：在 `Lamp_Light` 处放一盏暖色点光 #ffc977，半径 0.05。
- World 背景色 #f3dcc8，强度 0.6–0.8，作为环境光。
- 目标效果：明亮、温暖、阴影柔和，没有死黑的角落。

## 分阶段执行
1. 检查环境：Blender 版本、场景内容；建立三个集合和颜色转换工具函数。
2. 房间外壳：地台、地板、两面墙、踢脚线、窗户、墙面装饰 → 截图自检。
3. 家具：书桌、椅子、床、书架、地毯、盆栽、桌面小物 → 截图自检。
4. 可交互物体：Diary、Computer（含 Computer_Screen）、Lamp（含 Lamp_Shade、Lamp_Light）、Cat、Frame_1、Frame_2 → 检查原点和父子关系 → 截图自检。
5. Markers 和 PreviewCam、灯光 → 从 PreviewCam 用 Cycles 低采样渲染一张预览图。
6. **整体检查并停下**：发给我预览图，以及每个 Interactive 物体的名称、原点世界坐标、包围盒尺寸、三角面总数。等我确认。
7. 烘焙（我确认后）：
   - 把 `Static` 集合里的所有物体复制一份合并为一个网格 `Room_Static`，原来的物体隐藏备份。
   - 为 `Room_Static` 新建 UV（Smart UV Project，岛间距 0.02，或 Lightmap Pack），检查没有重叠。
   - Cycles，Bake 类型 Combined，2048 × 2048，采样 128 并开降噪，边距 8 px。保存为 `public/textures/baked-day.webp`；Blender 不支持 WebP 时保存为 PNG 并告诉我。
   - 可选：关掉台灯再烘焙一张 `baked-night.webp`。
   - 烘焙可能超过 MCP 调用的超时时间：先用 512 × 512、低采样试一次，确认流程跑通后再出正式图；如果超时，告诉我在 Blender 里手动执行的那段脚本。
8. 导出：
   - 只导出 `Room_Static`、`Interactive`、`Markers`，不导出相机、灯光和隐藏的备份物体。
   - 参数：GLB 格式，+Y Up，应用修改器，Draco 压缩级别 6，不导出图片（`export_image_format='NONE'`，版本不支持就去掉 Room_Static 材质里的图片节点再导出）。
   - 输出到 `public/models/room.glb`，文件大小目标 ≤ 2 MB。
