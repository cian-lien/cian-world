# 任务：用 Blender MCP 制作「夜晚氛围」的高精度等距房间模型（v2）

## 目标
为我的 3D 博客网站做一个俯视 3/4 视角的剖面小房间：夜晚、温馨、物件丰富、灯光有层次，质感接近一张精心渲染的「等距房间」插画。
我会附一张参考图，**只参考它的氛围、灯光手法和精细程度**。不要复刻参考作品中的具体物件、布局、玩偶或品牌标志。房间的内容按下文的设计来做。
所有光影最终都烘焙进贴图，网页端只显示贴图（不做实时光照），所以 Blender 里渲染出来是什么样，网页上就是什么样。

## 工作规则（必须遵守）
1. 开始前先用 MCP 查看场景和 Blender 版本（如 get_scene_info），告诉我版本号和场景里已有的物体。场景里不是你创建的物体，先问我再动。
2. 用 Python（bpy，如 execute_blender_code）分小步建模，每次只做一组物体。每段脚本都要能重复运行：先按名字删除旧对象，再重新创建。
3. 每个阶段结束后：从 `PreviewCam` 用 Cycles 低采样（32–64，开降噪）渲染一张预览图，自己检查比例、穿模、悬空、朝向、整体氛围，有问题先修好。
4. 每个阶段保存 `assets/blender/room.blend`，同时保留上一版 `room_prev.blend`。
5. **以下节点必须停下，发预览图给我确认后才能继续**：阶段 3（布局白模）、阶段 6（灯光氛围）、阶段 7（烘焙测试）。
6. 素材：主体家具和房间结构用脚本建模。绿植、书本、小摆件等复杂小物件，**允许**通过 MCP 的 Poly Haven 集成使用 CC0 模型和材质；不使用 Sketchfab 和 AI 生成模型（授权不明确）。用到的外部素材都记录到 `assets/CREDITS.md`（名称、来源链接、授权）。外部模型导入后要统一处理：缩放到合理尺寸、减面（Decimate）、换成本项目的配色材质，避免风格不统一。
7. 对象名是前端代码依赖的契约，必须和下文完全一致，区分大小写。
8. 单位为米，Z 轴向上。

## 风格定义
- **风格化写实**：家具比例接近真实、细节到位（抽屉把手、椅子滑轮、键帽、书脊、线材），但表面干净，没有写实划痕和脏污。
- 所有硬边都要倒角（Bevel，宽度 0.005–0.03），柔软的物体（被子、抱枕、懒人沙发）用细分曲面（Subdivision 2 级）加少量形变，看起来软而饱满。
- 材质：Principled BSDF，以纯色或简单程序纹理为主，Roughness 0.5–0.9。木地板做成一条一条独立的木板，每条颜色稍有不同，板缝清晰。布料用略高的 Roughness，可加 Sheen。
- 颜色设置：下文颜色是 sRGB 十六进制，设置 Base Color 前要转换成线性值：`lin = c/12.92 if c <= 0.04045 else ((c+0.055)/1.055) ** 2.4`
- 基础色调偏低饱和（米白、浅木色、灰蓝、墨绿），**饱和的颜色交给灯光**。

## 房间结构（剖面微缩模型）
- 房间中心在原点，地板顶面 Z = 0。地台 6.4 × 6.4，**厚 0.3**，四周切面露出来。
- 只有两面墙：后墙内表面在 Y = +3.0，左墙内表面在 X = −3.0，墙高 3.2、**墙厚 0.2**，墙顶的切面露出来。右侧（+X）和前方（−Y）敞开。
- 墙、地板的切面统一用深色 #2a2433，和室内的颜色形成对比，让模型看起来像被「切开」的。
- 墙面颜色：后墙 #e9e2f0（偏冷的灰紫白），左墙 #dcd3e6，踢脚线 #c9bfd6。

## 房间内容设计（原创布局）

### 后墙：工作区（视觉焦点）
- 长书桌，桌面中心 (0.5, 2.45, 0.76)，尺寸 2.3（X）× 0.8（Y）× 0.05，桌面顶面 Z = 0.80；浅木色桌面 #d9b38c；右侧一个三层白色抽屉柜代替桌腿，左侧是金属桌腿。
- 桌上：显示器（即 `Computer`，见下）、机械键盘（逐个做出键帽）、大桌垫 #2f2b3a、鼠标、耳机支架和耳机、马克杯、一小盆多肉、一叠便利贴、一个小音箱。
- 桌子上方墙面：两层浮板置物架，摆书、相机、小摆件、一盏小夜灯；**上层浮板底部有一条 LED 灯带**（见灯光）。
- 显示器后面的墙上有一块洞洞板（Pegboard），挂便签、照片、耳机、小工具。
- 线材：显示器、台灯、音箱的电线顺着桌腿垂下来，用曲线（Curve）加 bevel 做出来。

### 后墙右侧：窗户与绿植
- 窗户中心 (1.9, 3.0, 1.75)，窗框 1.0 × 1.4，白色窗框、窗台，两侧挂半拉开的布窗帘 #6c7aa6。
- 窗外放一块深蓝夜空背景板，上面有一轮月亮（自发光）和几点远处的城市灯光，玻璃略带反射。
- 窗边角落 (2.55, 2.55, 0) 放一大盆龟背竹或琴叶榕，叶片要有真实的形状和层次（可用 Poly Haven 模型）。

### 左墙：休息区
- 床，底部中心 (−2.35, −1.3, 0)，1.3（X）× 2.0（Y），床头靠 Y = −0.3 一侧：木床架、厚床垫、被子（自然褶皱和垂坠）、两个枕头、一个抱枕。
- 床头上方墙面挂一串**暖色小灯泡串**（Fairy lights），呈两段自然下垂的弧线，每个灯泡都是独立的小发光球。
- 床头柜放在床头旁边：小台灯、一本翻开的书、闹钟。
- 两个相框（`Frame_1`、`Frame_2`），挂在床上方的墙面。

### 后墙左侧：书架
- 书架（`Bookshelf`），底部中心 (−2.75, 1.6, 0)，靠左墙，0.4（X）× 1.2（Y）× 2.0（Z）。书本高矮、厚薄、颜色都有变化，部分斜放、部分平放成一摞，再穿插几个收纳盒和小盆栽。

### 地面
- 圆形地毯，中心 (0.4, −0.6)，半径 1.3，做出短绒质感。
- 一个懒人沙发（豆袋），放在地毯前侧。
- 猫窝和猫（`Cat`）放在地毯上靠近床的位置。
- 一台小型落地风扇或一个落地音箱（二选一）放在空地，丰富前景。
- 椅子：带滑轮的人体工学椅，面向书桌，绕 Z 轴略微转动。

## 灯光设计（决定成败的部分）
夜景，整体偏暗，由多盏有颜色的光撑起画面。所有灯都单独命名，方便调整：
| 灯名 | 类型 / 位置 | 颜色 | 作用 |
|---|---|---|---|
| `L_Moon` | 面光源，放在窗外，朝向室内 | 冷蓝 #7fa8ff | 主光：从窗户斜射进来，在地板和墙上投出窗框的影子 |
| `L_Fill` | 大面光源，放在房间右前上方（敞开的一侧），很弱 | 灰紫 #8b7fb8 | 补光，防止暗部死黑 |
| `L_Desk` | 点光或聚光，在 `Lamp_Light` 处 | 暖橙 #ffb066 | 台灯，照亮桌面和日记本，形成暖色中心 |
| `L_LED` | 置物架下方的长条面光源（或自发光灯带） | 紫红 #c45cff | 在后墙上洗出一道彩色光晕 |
| `L_Fairy` | 小灯泡串的每个灯泡做成自发光材质 | 暖黄 #ffd27a | 床头的温馨点光 |
| 显示器 | `Computer_Screen` 自发光 | 蓝紫 | 显示器在墙上投出的光 |
| 床头灯 | 小点光 | 暖黄 | 休息区补光 |

调灯光的目标：
- 画面三个区域分别有自己的主色调：工作区是紫色加暖橙，窗边是冷蓝，床边是暖黄。
- 墙面上能看到柔和的渐变和彩色光晕，地板上能看到灯光的反弹。
- 最亮的地方不过曝，最暗的地方依然能看出物体的轮廓。
- 色彩管理用 AgX（Blender 4.x）或 Filmic（3.x），Look 选 Medium High Contrast 一类。

## 分阶段执行
1. 检查环境：Blender 版本、场景内容；建立集合（`Static_Room`、`Static_Furniture`、`Static_Props`、`Interactive`、`Markers`、`Lights`）、颜色转换函数、PreviewCam。
2. 房间结构：地台、墙、踢脚线、窗户和窗外背景板、木地板（逐条木板）。
3. **布局白模**：所有家具用简单形状占位，确认构图、动线、比例 → **停下发图给我确认**。
4. 精细建模：家具细节、软装（被子、枕头、窗帘、豆袋）、可交互物体。
5. 小物件和装饰：桌面物品、书本、绿植、洞洞板、线材、小灯泡串。最后检查一遍面数。
6. **灯光和氛围**：按灯光设计布光，用 Cycles 渲染一张较高质量的预览图（采样 256，开降噪）→ **停下发图给我确认**。
7. **烘焙测试**：先只烘焙地板和墙（`Static_Room`），1024 分辨率，验证流程和效果 → **停下发图给我确认**。
8. 正式烘焙（见下）。
9. 导出（见下）。

## 烘焙方案
- 按图集分组，每组合并成一个网格，并单独展一套 UV（Smart UV Project 岛间距 0.01–0.02，或 Lightmap Pack）。每组一张 2048 × 2048 贴图：
  | 网格名 | 内容 |
  |---|---|
  | `Bake_Room` | 地台、墙、地板、窗户、窗外背景板 |
  | `Bake_Furniture` | 书桌、椅子、床、床头柜、置物架、洞洞板、地毯、豆袋 |
  | `Bake_Props` | 所有小物件、绿植、线材、小灯泡串 |
  | 可交互物体 | **不合并**，各自保持独立，但共用一张图集 `Bake_Interactive`（多物体同时烘焙到同一张图，UV 不能重叠） |
- 烘焙设置：Cycles，Bake 类型 Combined，采样 512–1024，边距 16 px。
- 降噪：烘焙结果用合成器（Compositor）的 Denoise 节点处理，或者用足够高的采样避免噪点。
- 保存：用 `image.save_render()` 保存，让 AgX/Filmic 色彩管理一起应用到贴图上，网页里看到的颜色才会和 Blender 预览一致。保存为 `public/textures/bake-<组名>-lampon.webp`；Blender 不支持 WebP 就存 PNG 并告诉我。
- 关掉 `L_Desk` 和台灯灯罩的自发光，再烘焙一套 `-lampoff` 贴图（网页里开关台灯时切换）。
- 烘焙可能超过 MCP 调用的超时时间：先用低分辨率、低采样跑通流程；如果正式烘焙会超时，把完整脚本给我，我在 Blender 里手动运行。

## 导出
- 只导出 `Bake_*` 网格、`Interactive` 和 `Markers` 集合；不导出相机、灯光、原始未合并的物体（隐藏留作备份）。
- 参数：GLB 格式，+Y Up，应用修改器，Draco 压缩级别 6，不导出图片（`export_image_format='NONE'`；版本不支持就先移除材质里的图片节点再导出）。必须保留 UV。
- 输出到 `public/models/room.glb`。
- 预算：三角面总数 ≤ 150,000；room.glb ≤ 4 MB；贴图每张 WebP ≤ 600 KB。
