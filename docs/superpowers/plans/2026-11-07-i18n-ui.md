# 多语言界面 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 完成已确认的中英文界面与资料接入，文章原文不变。

**Architecture:** 静态 TypeScript 词典和 i18next 共用实例；纯函数处理语言检测及 URL。资料翻译和共用数据放在稳定 ID 的记录中；现有 React 组件订阅语言更新，不按语言重建。

**Tech Stack:** React 18、Vite 5、TypeScript、i18next、react-i18next、Vitest 2。

**Spec:** `docs/superpowers/specs/2026-11-07-i18n-design.md`

## Global Constraints

- 只支持 zh-CN 和 en，URL > 手动选择 > 浏览器 > zh-CN。
- 文章和 Post/posts 接口不变，无英文 Markdown，无新后端。
- 参数/Hash/历史状态保留，切换无重载，不重建 Canvas 和桌面窗口。
- 共用身份、URL、技术栈；按稳定 ID 关联翻译。

## Review Focus

- localStorage 抛错：浏览器中仍可初始化、切换和刷新恢复 URL 语言。
- 历史条目语言不同：前进后退恢复对应语言及视图。
- drei 独立 DOM 根：桌面窗口即时更新而 DOM 与位置不重建。
- 英文内容较长：选择器与窄屏 HUD 不重叠，窗口内容可以滚动。
- 文章仍为中文：标题、正文及终端 ls 不被误翻译或过滤。
