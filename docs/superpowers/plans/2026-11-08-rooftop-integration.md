# 岭南天台程序集成 Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans. 用户早先授权直接完成所有阶段，本轮已批准第二版并完成模型；继续实现同一任务，无重复批准。模型阶段的“程序集成待后续”现在进入执行。

**Goal:** 将第二版天台模型接入可玩的世界，完成补充需求的移动、互动、天气、声音、共享窗景和验证。
**Architecture:** 延用纯环境store和现有声音引擎；新增纯导航/角色规则，R3F独立天台模块消费数据。共享城市组件同时供天台与房间窗景的离屏渲染使用。所有代码资源按需加载并释放拥有的GPU对象。
**Tech Stack:** React18/R3F8/Three0.169、TypeScript、Vitest、Cloudflare Worker、已有GLB资产。
**Spec:** 用户两个附件及第二版批准；模型资料 `assets/blender/rooftop/README.md`。

## Global Constraints
- 原房间模型/烘焙/交互不改；不推送或切换生产版本，只上传可分享预览。
- 8×7m屋顶、0.25m A*网格、1.2m/s、WASD/方向键/触摸点地面，障碍不可穿越，点物件先走近再触发。
- 真实天气决定降水；回南天=立春至清明期间、湿度≥90%、温度高于昨日同一时段；缺失数据不猜测。
- 雨伞、雨衣、≤12℃围巾、≥32℃葵扇；程序动画、有限镜头、可访问物件按钮。
- 5个完整主题，其余19个季节通用；两语；真实录音CC0或署名CC BY4.0；稳态4层/过渡总6源/等功率4秒规则保持。

## Review Focus
- 键盘输入时面板/文本焦点不移动角色；拖动镜头不触发地面移动；路径不能切障碍角。
- 天气数据缺失/过期/零湿度、昨天记录缺失时不得制造回南天。
- 快速进出世界和换装/节气切换的GPU资源释放，不覆盖房间曝光/环境。
- 静态模型的父子关系、局部变换不能因组合换装或动画被破坏。
- 首次手势前没有音频下载；声音更新继续满足4/6源约束及现有音频生命周期测试。
