## 覆盖的运行边界

- 广州、伦敦、悉尼、极地；太阳高度−6°/6°边界；日月角度与月相范围；连续dayProgress；无位置的设备墙钟投影不改变真实节气。
- 日期/时间单独或组合覆盖；纽约DST重复取早/缺失推进；24:00端点次日零点；1900/2100上下界在全球时区转换后仍可用。
- 所有指定WMO代码，包括冻雨和95–99兼容；非法码/NaN/Infinity/缺字段；强度/云量归一化、风向跨359°→1°短弧。
- 部分URL参数、非法日期、单边坐标、来源逐字段混合、显式位置与另一城市响应不匹配、过期/将来/坏响应。
- 存储禁用或坏JSON、只保存手动设置不保存位置；恢复真实保留lang/bake/cam/lamp、路径、编码Hash和history.state；旧浏览器没有URLSearchParams.size时也保留参数。
- 首次构造零请求/计时器、多次start与重复清理、订阅取消、隐藏暂停/恢复、实时交节边界、迟到/取消请求、数据到达不覆盖手动或URL。
- 雨雪雾/云/湿度等4秒数值过渡、反向改目标从当前值接续、雪只按snow增长/离开后融去；未接任何渲染器或声音系统。

## 测试先行与独立审阅

先运行了缺模块的失败测试，再实现各模块。最初的双体太阳简式虽通过48个日期，但12个时分样本超5分钟，因此保留原断言并补周期项，没有修改权威样本来迁就算法。

独立只读审阅发现4项问题，均补回归测试，观察失败后修复，并通过全套176项测试：

| 问题 | 修复与回归 |
| --- | --- |
| API缓存已14分钟旧，但store从接收时再等15分钟 | 按原始fetchedAt的实际到期调度；持续返回过期数据时仍有界重试，不紧密循环 |
| 合法模拟日期经时区换算超出内部年表边界 | 内部容纳相邻北京时间年份，覆盖Sydney下界/Los Angeles上界 |
| 坏DTO把有效城市清空，导致昼夜跳变 | 与网络异常统一处理：保留会话内最后有效位置，天气fallback |
| URLSearchParams.size不兼容旧目标浏览器 | 用序列化结果是否非空判断，恢复真实不丢其他参数 |

没有未修复的重要审阅项。独立审阅不涵盖尚未实施的Worker、画面/音频或运行性能，也未重新核对原始HKO PDF；原始样本由本次实施时核对。
